# 资料接收与旧记录核对

用户提供教材、教辅或资料文件，并要求导入学习库、接入教学、登记或更新记录时使用。目标是让原文件、资料登记与现有 Markdown 中的当前状态一致；聊天中识别出书名不等于文件已保存或旧记录已更新。

## 接收与读取分别确认

记录此次明确提供的文件及其实际位置，区分聊天临时附件、库内文件、只有目录名与无法访问的文件。不凭文件夹名称断言存在教材全文；不能访问另一台电脑时直接说明，不能根据截图声称已写入。

只记录已实际核对的信息：文件可用性、书名、版次、文件类型、已读范围及尚未识别的部分。封面只支持封面信息；目录只支持目录；读取局部不表示全书已索引。页码区分 PDF 页与印刷页，映射未核对时保留待确认。

## 何时写回

用户要求导入、登记、接入已确认的学习库或修正记录时，资料登记及修正本次受影响的“尚未提供资料”等当前状态属于该任务，直接完成，不额外等待“归档学习进度”的口令。登记资料不等于生成学习笔记或更新掌握程度。

用户仅上传文件并让解释一道题，或仅问文件内容时，可以按当前任务读取，不自动取得修改任意旧文档的权限。若当前已授权的库维护范围包含资料登记，则沿用它；仍缺库路径或写权限时继续教学，同时明确登记未完成、缺什么，不能假称已经记录。

## 更新已有 Markdown

先在已确认库的相关资料目录、资料登记页、使用指南和首页做有限查找，读取与此次文件有关的当前段落及上下文，不全盘扫描。

- 已有同一教材、版本和文件记录时复用条目、ID 和链接；重复接收同一文件不重复新建。
- 有资料登记页就沿用；没有时只在本次授权范围内建立一份可读主题命名的资料目录，记录真实相对路径、已核对信息与未核对范围。
- 核对“暂未提供教材原文件”“等待上传”等当前断言是否已经过时。只修正被新证据推翻的句子；不能把历史记录里的“当时未提供”抹掉，也不能把所有待确认项一概改成已完成。
- 具体文件已读而版本未核对时可写“资料文件已接收并可读取；版次待核对”；目录已读但正文未读时写清两者范围。不要用“教材已接入”暗示全书可检索、全部页码已核对。
- 保留“不捏造章节页码”等长期规则。截图示例里的旧句可拆成真实的当前资料状态，加上“仅引用实际核对的章节与页码”；不能为了改掉“未提供”而删掉来源核验要求。
- 只更新本次相关的指南、来源说明与导航链接；不改用户自己的学习理解、自写笔记、已学状态或无关教学计划。

已有文件按维护规则先备份，写入前检查并行改动，再做最小补丁。没有维护技能时在当前授权内执行同等检查，不虚构已经转交或调用其他代理。

## 写后回读才算完成

重新读取实际写入的文件，核对新记录及旧句的修正位置、来源字段、链接和附件可达性。相关段落仍过时时不能只说“资料已识别”就结束；写入失败要逐项说明已读取与未保存的区别。

交付时列出：接收了什么、实际读到哪里、哪些 Markdown 已新增或修改、备份位置，以及尚未核对的内容。未改文件就明确说未更新，不能以已生成草稿或聊天摘要代替落盘证据。

## 截图反馈的证据边界

截图可证明画面中有教材目录和“暂未提供”这句话，不能证明具体文件是否持久保存、某章节是否读完或 AI 是否获得更新授权。远端资料库不在本机时，修复工具箱规则与修复该库是两项不同结果；需要在实际可访问的库里再次执行接收登记和旧记录核对。
