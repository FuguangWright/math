# 基于实测完善复盘与拓展

日期：2026-11-02；版本：0.5.1。

授权与依据：用户在学习会话明确要求复盘功能完善，并授权复盘后把反馈交给技能维护会话。本轮只读核对学习过程记录、两道题的路线及AI拓展档案，不修改这些档案，不将其正文、个人路径或学习状态拷入源码仓库。下述实现取自反馈分析，不把会话整理的每条建议冒充用户逐项批准。

改动：think/SKILL.md及strict-guidance、research-workflow、retrospective三份引用文档；增加有范围的复盘许可、新证据关闭旧卡点、分子问记录来源、从目标反推构造的解释与有用拓展的组织。同步版本说明、升级摘要与行为检查用例。

行为选择：严格模式下询问有无拓展不自动解除限制；用户已明确允许本次复盘的新方法与公式时直接展开，不逐项重复确认。范围限本次已完成内容，结束后恢复原研究边界，除非用户明确持续切换。只允许思路或只允许公式时保留另一项限制。未知或未完成的其他子问仍不泄露。

复盘要求：沿真实尝试解释关键转折，按目标和条件说明比较对象、辅助对象或递推界如何被约束；不把事后系统解释伪装成当时独立发现。区分早期提示、后续自主补证、获准的AI拓展及常规书写补充；原题完成与拓展掌握分别记录。提示额度按关键决定及累计泄露判断，不按字数。

证据范围：历史实测显示提示过量及用户收紧模式的反馈，也显示明确授权后的拓展交付与后续补齐证明。这是修订前案例核对，不是新版已通过实测的证明。新增用例仍待独立对话验证，结构和部署检查结果在执行后追加。
